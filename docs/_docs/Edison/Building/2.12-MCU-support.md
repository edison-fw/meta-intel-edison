## MCU driver
We added support to the LTS kernel with "linux-yocto: add new MCU patches + cfg" and "linux-yocto: LTS add MCU support".

## Quick start
The Edison Wiki contains [Quick start](https://edison-fw.github.io/edison-wiki/edison-MCU-quick-start) guide as well as API and SDK documentation salvaged from Intel web site.

## Auto-load MCU programs
For now this is disabled but you can enable it by `systemctl enable mcu_fw_loader`.
